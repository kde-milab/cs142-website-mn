MERN програм суулгах заавар

Энэ хичээлийн төслүүдийг хийхэд дараах програмууд хэрэгтэй. Эхний төслүүдэд (1–4) вэб хөтөч, код засварлагч, Node.js хангалттай. MongoDB-г 6-р төслөөс эхлэн ашиглах тул улирлын эхэнд бүгдийг нь суулгаж бэлтгэхийг зөвлөж байна. Linux, macOS, Windows аль ч үйлдлийн систем дээр ажиллана.

1. Вэб хөтөч ба код засварлагч

  • Google Chrome — хичээлд Chrome-г зөвлөж байна. Хөгжүүлэгчийн хэрэгслийг (DevTools) F12 эсвэл Ctrl+Shift+I (macOS дээр Cmd+Option+I) товчоор нээнэ.
  • Visual Studio Code — зөвлөж буй код засварлагч. Өөр засварлагч (Sublime Text г.м.) ашиглаж болно.

2. Node.js суулгах

Node.js-ийн хамгийн сүүлийн LTS (Long Term Support — урт хугацаанд дэмжих) хувилбарыг суулгана. Үүнийг https://nodejs.org/en/download хаягаас татаж авна. Node.js-тэй хамт модуль менежер npm суудаг бөгөөд үүгээр төслийн эхлэл файлууд болон хамаарлын сангуудыг татна.

Суусан эсэхийг шалгахдаа терминал (Windows дээр PowerShell) нээгээд дараах командуудыг ажиллуулна: 

node -v
npm -v

Хоёр програмын хувилбарын дугаар гарч ирвэл амжилттай суусан байна. Командыг танихгүй байвал терминалаа хаагаад дахин нээж үзээрэй.

3. MongoDB суулгах

MongoDB Community Server-ийг үйлдлийн системдээ тохирох суулгах зааврын дагуу суулгана.

MongoDB-тэй командын мөрөөр ажиллах mongosh (MongoDB Shell) нь серверээс тусдаа суудаг тул https://www.mongodb.com/try/download/shell хаягаас татаж суулгана. Өгөгдлөө график интерфейсээр харах бол MongoDB Compass-ийг нэмж суулгаж болно (заавал биш).

Серверийг асаах

Windows дээр суулгагч MongoDB-г ихэнхдээ Windows Service болгон суулгаж, компьютер асахад автоматаар ажиллуулдаг. Service болгоогүй, эсвэл Linux/macOS дээр гараар асаах бол өгөгдлийн сангийн хавтсаа зааж ажиллуулна: 

mongod --dbpath <өгөгдлийн_сангийн_хавтас>

Сервер ажиллаж байгаа эсэхийг шалгахдаа өөр терминалаас дараах командыг ажиллуулна: 

mongosh

Холбогдсоны дараа help гэж бичээд боломжит командуудыг, show dbs гэж бичээд өгөгдлийн сангуудыг харна. exit командаар гарна.

Windows хэрэглэгчдэд

mongod командыг танихгүй бол MongoDB суусан хавтсыг Windows-ийн Path орчны хувьсагчид нэмнэ. Ихэнхдээ дараах зам дээр суусан байдаг: 

C:\Program Files\MongoDB\Server\<хувилбар>\bin

(Эхлэх цэс → "Edit the system environment variables" → Environment Variables → Path → New.) Дараа нь терминалаа дахин нээнэ.
